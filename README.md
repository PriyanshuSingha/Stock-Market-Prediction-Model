# 📈 StockVision

StockVision is a web-based stock price prediction system using Machine Learning and Deep Learning.

## 🚀 Features
- Predict stock prices
- Uses Linear Regression, Random Forest, LSTM
- Interactive charts
- User authentication

## 🛠️ Tech Stack
- Python, Django
- TensorFlow, scikit-learn
- HTML, CSS, JavaScript
- MySQL

## 📊 How it Works
1. User enters stock symbol
2. Data fetched from Yahoo Finance API
3. Models predict future prices
4. Results shown in dashboard
